# Replication Files for "International Reserves, Global Financial Risk, and the Composition of Foreign Equity Investment in the Recent Era of Financial Globalization"

**Alaa Al-Bashir**

## Overview

This repository contains the Stata code and data required to reproduce the empirical results and figures reported in the paper.

The analysis uses an annual panel of 110 countries over 2001–2020 and examines the relationships among the composition of foreign equity investment, international reserves, and global financial risk.

## Software Requirements

The replication package was prepared and tested using:

- StataNow/SE 19.5 for Windows (64-bit)

The master do-file checks for and, when necessary, installs the following user-written Stata packages:

- `xtendothresdpd`
- `locproj`
- `xthreg`
- `moremata`

See `software_versions.txt` for the software environment used for the final replication run.

## Repository Structure

- `master.do` — master replication file that runs the complete analysis.
- `variable_dictionary.xlsx` — crosswalk between variable descriptions, Stata variable names, and notation used in the paper.
- `software_versions.txt` — software and user-written package information for the replication environment.
- `data/input/` — source data files used to construct the analysis dataset.
- `data/derived/` — location of the analysis dataset generated by `master.do`.
- `output/figures/` — figures generated by the replication code.
- `output/logs/` — Stata replication log generated by `master.do`.
- `output/tables/` — reserved for generated table files where applicable.

## Replication Instructions

1. Clone or download this repository.
2. Open StataNow/SE 19.5.
3. Set Stata's working directory to the root directory of the repository.
4. Run:
