# References

This folder contains bibliographic information related to the associated paper.

## Local PDF Library

PDF copies of cited articles are maintained locally for the author's research use and are not distributed through this GitHub repository.

The local `pdfs/` directory is excluded through `.gitignore`.

## Bibliographic Information

Complete references, data-source citations, and publication details are provided in the associated paper.

Future versions of this repository may also include a machine-readable bibliography such as `references.bib`.
